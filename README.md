
<h1>Painel de Controle Mestre (PCM) 🧮 </h1>

<hr>

{=} Aplicação customizada criada com o objetivo de auxiliar em minha organização de tarefas e controle de abas. {=}

A aplicação busca sumarizar tudo que posso querer acessar em um só lugar, me ajudando a manter menos abas <br>
abertas de uma vez e servindo como estudo de tecnologias web

<hr>

<h3>O Sistema deve ter</h3>
- Uma interface agradavel e de facil esalabilidade <br>
- Uma playlist de musicas de ambiente <br>
- Links importantes (google drive, deepseek, youtube, github, etc) <br>
- Local de destaque de tarefas importantes <br>
